## 導覽層級

```
學習範圍（年級）→ 選科目 → 選版本 → …
                              ├─ 課綱自編版  → 進去跟以前完全一樣（現有首頁，一行都不改）
                              └─ 康軒版      → 選系列 → 選課 → 選單元 → 重點整理 → 20 題練習
```

- 「版本」是科目底下的一層，不是全站設定：`state.edition[<科目>]`，預設 `core`（課綱自編版）。
- 某科只有一個版本時不跳版本頁，直接進去（現在只有國語有兩個版本）。
- ⛔ 課綱自編版的行為一律不動。這次所有新東西都掛在康軒版底下，出錯也不會波及舊的。

## 資料結構（js/data/edu-<版本>-<科目><冊>.js）

```js
window.APP_EDU = window.APP_EDU || [];
window.APP_EDU.push({
  id: 'kx-c5a-idiom-01-1',      // <版本>-<科目><冊>-<系列>-<課次>-<單元>
  edition: 'kangxuan', subject: 'chinese', book: '五上',
  series: 'idiom',              // words | idiom | quiz（對應交辦的 1/2/3）
  lesson: 1, lessonName: '蚊帳大使', unit: 1,
  title: '成語加油站（一）認識意思',
  brief: {                      // 「重點整理」：讀完才開始作答
    intro: '…一段導讀…',
    rows: [{ t: '聚蚊成雷', d: '釋義…', e: '例句…' }, …],
    tip: '…一句提醒…'
  },
  qs: [ { t:'choice'|'write'|'match', q, options, answer, exp, … } × 20 ]
});
```

- `t:'choice'` 四選一（沿用現有 quiz 引擎）
- `t:'write'`  手寫題（看注音寫國字，沿用 view-write 的畫布與自評）
- `t:'match'`  配合題（左欄題目、右欄代號選項，沿用匯入題庫「配對」題型的作法）

## 素材

- 成語：`docs/source/kangxuan-5a-idioms.json` — 12 課 133 條，含釋義與自撰例句。
  來源是 Drive 上「成語加油站（教）」12 份 PDF，經 Drive MCP 取文字後還原
  （直排 PDF 的字序是亂的，但釋義區與填空區列的是同一組成語，兩邊對照即可還原成語清單）。
- 生字表 / 字音字形 / 挑戰小學堂：待 rclone 授權後用 `pdftotext -layout` 取得。

## 硬規則

- ⛔ 題目與例句一律自撰，不抄原題本原題（版權）。重點整理的釋義以教育部《成語典》《國語辭典簡編本》為準。
- 注音一律對教育部《國語辭典簡編本》，不可憑印象（CLAUDE.md「注音的唯一依據」）。
- 每題解析要有「✅ 正解為什麼對」＋「❌ 其他選項各錯在哪」。
- 誘答不可用選項長短就猜得出答案（test.js 有守門）。
